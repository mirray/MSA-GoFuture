Изоляция данных - на уровне кластера kubernetes.   

Для каждого нового тенанта разворачивается свой кластер k8s в регионе присутствия.  

При таком подходе каждый тенант получает полную изоляцию данных, нагрузки на одного тенанта никак не влияют на производительность другого тенанта.

Доступ пользователей к кластеру осуществляется через OIDC.
